## 📌 Featured Projects

### ⚡ High-Performance Order Matching Engine

<p align="center">
  <img src="https://img.shields.io/badge/C%2B%2B-Systems-00599C?style=flat-square&logo=cplusplus&logoColor=white" />
  <img src="https://img.shields.io/badge/Trading-Systems-222222?style=flat-square" />
  <img src="https://img.shields.io/badge/Low--Latency-Engineering-8B5CF6?style=flat-square" />
</p>

A high-performance **central limit order book and matching engine** built from scratch in C++. The engine receives buy and sell orders, maintains them according to **price-time priority**, and automatically matches compatible orders to generate trades.

The project focuses on understanding how real trading infrastructure handles **order management, matching logic, memory-efficient data structures, and low-latency execution**.

**Current work:**

- Central Limit Order Book
- Price-Time Priority Matching
- Buy/Sell Order Management
- Order Cancellation
- Trade Execution
- Low-Latency Data Structures
- Performance Benchmarking

### 🚦 Distributed Rate Limiter

<p align="center">
  <img src="https://img.shields.io/badge/C%2B%2B-Systems-00599C?style=flat-square&logo=cplusplus&logoColor=white" />
  <img src="https://img.shields.io/badge/Redis-Distributed%20State-DC382D?style=flat-square&logo=redis&logoColor=white" />
  <img src="https://img.shields.io/badge/Docker-Containerized-2496ED?style=flat-square&logo=docker&logoColor=white" />
</p>

A distributed API rate-limiting system designed to **control and limit request traffic across clients and application instances**. Redis is used as shared state so rate limits remain consistent even when requests are handled by different application processes.

The project explores real-world rate-limiting strategies, **concurrency, distributed state management, atomic operations, and performance under high request volume**.

**Implemented / Exploring:**

- Token Bucket
- Leaky Bucket
- Fixed Window Counter
- Sliding Window
- Redis-based Distributed State
- Thread-Safe Request Handling
- Lua Scripting
- Dockerized Development
